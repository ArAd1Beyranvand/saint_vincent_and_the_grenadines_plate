# saint_vincent_and_the_grenadines_plate

Saint Vincent and the Grenadines's licence plates for the plate_core library — the one letter, four digit plate, off-white on black, with an advisory validator.

## Quick start

### Install (Kotlin)

Copy `kotlin/src/commonMain/kotlin/plates/countries/saint_vincent_and_the_grenadines/` into `plate_core/kotlin/src/commonMain/kotlin/plates/countries/`.

Then run the tests from `plate_core/kotlin/`: `./gradlew jvmTest`.

### Use

```kotlin
import plates.countries.saint_vincent_and_the_grenadines.country

val spec = country.specs["vc.private"]
println(country.pkg)
```

## Specs

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`SaintVincentAndTheGrenadinesValidator`).

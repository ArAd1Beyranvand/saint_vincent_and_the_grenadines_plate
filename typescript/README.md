# saint_vincent_and_the_grenadines_plate

Saint Vincent and the Grenadines's licence plates for the plate_core library — the one letter, four digit plate, off-white on black, with an advisory validator.

## Quick start

### Install (TypeScript)

Copy `typescript/src/countries/saint_vincent_and_the_grenadines/` into `plate_core/typescript/src/countries/`.

Then run the tests from `plate_core/typescript/`: `npm test`.

### Use

```ts
import country from './countries/saint_vincent_and_the_grenadines';

const spec = country.specs.get('vc.private');
console.log(country.package);
```

## Specs

The specs are the same in every language (they come from shared data).

## Themes

- `SaintVincentAndTheGrenadinesThemes.private`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`SaintVincentAndTheGrenadinesValidator`).

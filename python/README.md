# saint_vincent_and_the_grenadines_plate

Saint Vincent and the Grenadines's licence plates for the plate_core library — the one letter, four digit plate, off-white on black, with an advisory validator.

## Quick start

### Install (Python)

Copy `python/plates/countries/saint_vincent_and_the_grenadines/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.saint_vincent_and_the_grenadines.data import SPECS, THEMES

spec = SPECS["vc.private"]
theme = THEMES["SaintVincentAndTheGrenadinesThemes.private"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `vc.private`

## Themes

- `SaintVincentAndTheGrenadinesThemes.private`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `SaintVincentAndTheGrenadinesValidator` to classes.
